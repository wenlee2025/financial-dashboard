# ADR 0001: 本地優先與免 API 動態量化推理架構

## 狀態
Accepted (已採納)

## 上下文與決策 (Context & Decision)
為了支援使用者在本地端進行格式驗證、數據檢查與免 API Key 運行，系統採用**本地優先（Local-First）**與**雙模態推論架構**：
1. **多源數據本地聚合**：TWSE 官方開放數據、yfinance 即時行情、FRED 美債殖利率與 CNN 恐慌貪婪指數均在本地直接獲取與計算。
2. **動態量化推理引擎**：當未配置外部 LLM API Key 時，系統自動啟用內建之動態量化邏輯引擎，根據當日即時廣度、法人籌碼流向、均線型態與 ADR 溢價率合成具備深度投研水準的質化報告與操作清單。
3. **本地預覽伺服器**：提供 `python main.py --serve` 一鍵啟動本地 Web 伺服器進行即時互動檢視，完全無需上傳 GitHub 即可完整驗證儀表板內容與格式。
