# ADR 0014: 雙層多智能體激辯與風控一票否決架構 (Two-Tier Deliberation & Downside Veto Architecture)

## 狀態
Accepted (已採納，基於 TradingAgent 專案整合審計與 Round 1 設計共識)

## 上下文 (Context)
在將 TradingAgent 深度多智能體（Multi-Agent）決策體系整合至財經儀表板時，面臨核心工程與投資哲學權衡：
1. **API 額度與排程時效性瓶頸**：
   系統每日監控 50 檔台美股票。若對每檔個股均發動 4~5 輪完整的 LLM Agent（基本面研究員、技術面研究員、多空辯論、風控審查）交互，每日將消耗超過 200 次大模型調用，排程耗時將膨脹至 15~20 分鐘，且在 CI 環境面臨嚴重的 API 429 Rate Limit 與 503 伺服器超載。
2. **客觀量化底線 vs LLM 隨機幻覺**：
   純大模型文字對話存在幻覺風險，若允許 LLM 自由捏造或隨意上調分數，將破壞量化模型（均線、ATR、三大法人籌碼、營收年增率）的數學客觀性與歷史回測有效性。

## 決策 (Decision)

經設計樹推演與共識審查，確立以下四大核心架構決策：

### 1. 雙層金字塔推論架構 (Two-Tier Architecture)
- **第一層：全市場量化底座 (Tier 1: 50 檔全量客觀定錨)**
  所有 50 檔標的均由深模組 `EquityEvaluator` 統一計算客觀多空評分（0~100）、ATR 關鍵操作點位（S1/S2/R1/R2、SL/TP）與 5 大決策原型動作。
- **第二層：TradingAgent 頂層多智能體審查 (Tier 2: 焦點標的深度激辯)**
  由 `DeliberationEngine` 調用結構化多角色激辯，聚焦於關鍵標的進行質性反轉辨析與風控審查。

### 2. 精準激辯範圍收斂 (Targeted Deliberation Scope)
激辯範圍精確鎖定於以下 3 類高敏感標的（共約 10~15 檔）：
1. **投資組合持倉標的 (Portfolio Holdings)**：結合持倉成本與損益，進行四宗師論文漂移審計（Thesis Drift Audit）。
2. **多空極端標的 (Top 5 Bulls & Top 5 Bears)**：對市場最強勢進攻與最弱勢破線標的進行雙向壓力測試。
3. **多空分歧爭議標的 (Divergent Stocks)**：量化得分高但遭遇主力爆量拔檔、外資期貨巨額壓盤或技術指標背離之標的。

### 3. 風控委員會一票否決制 (Downside Veto-Only System)
- **單向防守約束**：TradingAgent 的激辯結果**不得擅自上調**個股量化分數或無憑據追多。
- **一票否決最高權限**：當風控委員會偵測到重大風險（如跌破 ATR 停損、主力天量倒貨假突破、月營收斷崖式衰退）時，擁有一票否決權：
  - 強制將建議動作改寫為「🚨 警戒撤退 (風控否決)」或「🛡️ 嚴禁進場 (一票否決)」。
  - 於前端卡片標記雙系統分歧警訊（Divergence Warning）。

### 4. 確定性量化降級與零 NaN 保證 (Deterministic Fallback)
- 在無 API Key、網路中斷或遭遇 API 429/503 時，系統自動無縫降級為 JEV System 1 快思規則推論。
- 嚴格維持零 NaN 保證，絕不因外部 LLM 異常阻斷儀表板自動生成發布。

## 後果與價值 (Consequences)
- **效能與成本最優化**：每日排程控制在秒級完成，API 消耗降低 75% 以上，杜絕 CI 逾時風險。
- **立於不敗之地 (Pit of Success)**：將 AI 多智能體定位為「守門員」而非「吹鼓手」，徹底杜絕高檔盲目追多與社群雜訊幻覺。
