# ADR 0002: 成交總值 5MA 資金動能策略整合

## 狀態
Accepted (已採納)

## 上下文與決策 (Context & Decision)
單純依賴「成交張數（Volume）」容易在高價股（如大立光、信驊）與低價股（如華邦電、仁寶）之間產生流動性與量能判斷的嚴重失真。
為了更精確衡量實質大資金在每一檔標的上的承接與換手力道，系統決定在個股量化模型與儀表板中全面整合**成交總值 5MA（5-Day Turnover MA）**策略：
1. **多空 4 態判別**：結合股價 5MA 走勢與成交金額 5MA 斜率，劃分「強勢主升（追多）」、「動能衰竭（減碼）」、「量縮築底（潛伏）」與「爆量出貨（防守）」。
2. **多因子評分連動**：將成交總值動能狀態納入技術/籌碼評分加減分項與警報系統。
3. **前端雙視圖可視化**：在卡片與清單表中顯示「當日成交金額 / 5MA金額 / 金額量比 / 策略訊號標籤」，並支援上下即時排序。
